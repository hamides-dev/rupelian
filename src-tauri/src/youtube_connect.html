Use the account already in this browser

This connection stays in this tab and uses your current browser profile. No separate window, new profile, or repeated sign-in.

Install the Rupelian connector once in this browser profile, then reload this tab.

One-time browser connector setup
  1. Open chrome://extensions in another tab (Edge: edge://extensions).
  2. Enable Developer mode, choose Load unpacked, and select this folder:
    {{extension_path}}
  3. Return here and reload this tab. Click Connect my current YouTube account.

این افزونه فقط یک بار روی همین پروفایل نصب می‌شود. پس از نصب، همین تب را رفرش کن و دکمهٔ اتصال را بزن؛ نیازی به ورود دوباره نیست.

Check your account: Open YouTube in a new tab. Keep the account you want signed in, then return here.

The connector sends only YouTube cookies to the running player on this PC after you click Connect. The player encrypts the saved access for your Windows account. Nothing is uploaded to another service.
