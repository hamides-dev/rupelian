Rupelian - YouTube Browser Connector

1. Open chrome://extensions in the browser profile already signed in to YouTube.
2. Enable Developer mode and choose Load unpacked.
3. Select this connector folder. In Edge, use edge://extensions instead.
4. In Rupelian, open Settings > YouTube > Connect browser.
5. Paste the connection link into that same browser profile. Reload the tab if it was already open.
6. Click Connect my current YouTube account. You do not need to sign in again.

The connector does not create browser profiles or open managed sign-in windows.
Only a trusted Connect click transfers YouTube cookies directly to the running app on this PC.
Cookie values are not written to the page, browser local storage, or a plaintext export.
The app encrypts saved access with current-user Windows DPAPI.
Use Disconnect in Rupelian to remove saved playback access. Removing this extension does not sign you out of YouTube.
This development connector is installed with Load unpacked; a browser-store release is not available yet.

Connector v3 transfers playback access only. Reload it once in the extension manager after updating.
