Rupelian - Windows x64 Single EXE

Run the EXE. This format does not install the app or require administrator access.
The native loading window appears before the main player initializes.
On first use, the embedded runtime is extracted into Local App Data\Rupelian\portable-runtime.
The verified runtime cache remains after exit and is reused on later launches.

This format requires Windows 10/11 x64 with Microsoft Edge WebView2 Runtime already installed.
WebView2 and its installer are not included or installed automatically.
The media engine, yt-dlp, Deno, FFmpeg, and supporting runtime files are embedded.
YouTube playback requires network access to YouTube.

Settings, vocabulary, and saved translations live in Documents\Rupelian.
API keys and saved browser playback access are encrypted for the current Windows account.
See THIRD-PARTY-NOTICES.txt and licenses/ for third-party components.
This is a development distribution; a signed stable global release is not available yet.
