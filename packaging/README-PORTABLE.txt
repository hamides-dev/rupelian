Rupelian Portable - Windows x64 with Fixed WebView2

Extract the complete archive and run Rupelian.exe.
Keep WebView2Runtime/, binaries/, lib/, and the runtime DLL beside the EXE.
This optional distribution includes a fixed WebView2 Runtime and the media helpers.
Node.js, Rust, Visual Studio, and separately installed media tools are not needed on the target PC.

Settings, vocabulary, and saved translations live in Documents\Rupelian.
API keys and saved browser playback access are encrypted for the current Windows account.
