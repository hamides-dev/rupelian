Rupelian - Windows x64 Portable Folder

1. Extract the complete archive before opening the app.
2. Run Rupelian.exe.
3. Keep every adjacent file and folder together; do not move the EXE alone.
4. This format uses the Microsoft Edge WebView2 Runtime already installed on Windows 10/11. It does not include or install WebView2.
5. Settings, vocabulary, and saved translations live in Documents\Rupelian and remain after this app folder is removed.
6. API keys and saved browser playback access are encrypted for the current Windows account.
7. The folder includes the native media engine, yt-dlp, Deno, FFmpeg, and FFprobe. See THIRD-PARTY-NOTICES.txt and licenses/.

This is a development distribution. A signed stable global release is not available yet.
